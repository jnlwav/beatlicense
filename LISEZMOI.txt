BEATLICENSE — site web (HTML + CSS + JavaScript)

Utilisation : double-cliquez sur index.html. Aucune installation nécessaire.
Pour le mettre en ligne : envoyez tout le dossier chez n'importe quel hébergeur de sites statiques
(GitHub Pages, Netlify, Cloudflare Pages, ou un hébergement classique).

PDF : sur la page d'un contrat, cliquez « Télécharger le PDF », puis choisissez
« Enregistrer au format PDF » dans la fenêtre d'impression.

Données : les contrats sont enregistrés dans le navigateur de l'utilisateur (pas de serveur).
Utilisez Paramètres > Exporter mes contrats pour faire une sauvegarde.

Fichiers : css/style.css (design), js/engine.js (clauses et règles), js/app.js (pages et formulaire).

AVERTISSEMENT : les clauses sont des modèles à faire valider par un juriste spécialisé.
Dans js/engine.js, VALIDATED reste à false tant que ce n'est pas fait ; chaque contrat l'indique.

POLICES : Manrope (interface) et Source Serif 4 (contrats) se chargent depuis Google Fonts quand l'appareil est en ligne.
Hors connexion, le site utilise des polices de secours (Georgia pour les contrats).
Le thème est clair par défaut sur tous les appareils ; changeable dans Paramètres.
